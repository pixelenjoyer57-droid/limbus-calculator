# License proposals (NOT in force)

Nothing here is a license of this repository until the owner copies a file to the repository root. These are drafts, not legal advice.

| Option | Code | Game data | Effect |
|---|---|---|---|
| A (permissive) | MIT | CC BY-SA 4.0 | Anyone may reuse, fork and commercialise the code; data stays share-alike as required. Simple, most common. |
| B (patent grant) | Apache-2.0 | CC BY-SA 4.0 | Like A, adds an explicit patent grant and NOTICE handling; slightly heavier. |
| C (share-alike code) | AGPL-3.0 / GPL-3.0 | CC BY-SA 4.0 | Forks must publish source; discourages closed or commercial forks. Not compatible with every contributor wish. |
| D (nothing) | all rights reserved (current) | CC BY-SA 4.0 forced anyway | Others may view but not legally fork the code; the data is still CC BY-SA. Contradicts open Discord contributions. |

Whatever you pick, the data in `public/gamedata/` must remain CC BY-SA 4.0 (ShareAlike) and Project Moon's official text stays theirs. The files `LICENSE-code-MIT.md.proposal` and `LICENSE-data-CC-BY-SA-4.0.md.proposal` are the drafts for option A. Replace `<YEAR>` and `<OWNER NAME>`. For contributions, see `CONTRIBUTING-TERMS.md.proposal`.
