# Security policy

Sinner's Workshop is a static, client-only web app: there is no server, no account system and no analytics. Your work is stored in your own browser, and the only network requests the app makes are for its own files and its game-data files.

## Reporting a vulnerability

Please report security problems **privately** using GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the problem (what you did, what happened, which browser).

Please do not post exploits in public issues or in the Discord. You can expect an acknowledgement within a few days. This is a hobby project run by volunteers, so fix times are best-effort.

## What is in scope

- A share code, backup file or imported item that runs script, freezes or crashes the tab, or damages other saved workshops.
- Anything that makes the app send your data somewhere other than the site it was loaded from.
- Weaknesses in the build or deploy workflow (for example a way to publish altered files).

## Good practice for users

- Share codes and backup files are plain data, but only import ones from people you trust, and keep your own backup first (the app offers **Undo** after an import).
- Install or update the app only from its official GitHub Pages address.
